# Dual-Desktop Workflow Comparison

A comparison of key workflows across both desktop sessions.

---

| Action | 🪟 Windows 11 (KDE Plasma) | 🌌 Omarchy (Hyprland Tiling) |
| :--- | :--- | :--- |
| **App Launcher** | `Super` (Centered Start Menu) | `Super + Space` (Wofi) |
| **Terminal** | `Ctrl + Alt + T` | `Super + Return` (Alacritty) |
| **Browser** | Taskbar Icon or `Super + B` | `Super + B` or `Super + Shift + B` |
| **File Manager** | `Super + E` | `Super + E` or `Super + Shift + F` |
| **Close Window** | `Alt + F4` or Titlebar [X] | `Super + Q` or `Super + W` |
| **Window Layout** | Freeform Floating / Snap Assist | Automatic Dwindle Tiling |
| **Toggle Floating** | Default | `Super + T` |
| **Fullscreen** | `F11` | `Super + F` |
| **Workspace Navigation** | Desktop Grid / Taskbar Pager | `Super + 1..0` |
| **Theme Customization** | System Settings &rarr; Appearance | `Super + Ctrl + Shift + Space` (22 Themes) |
| **Clipboard History** | Plasma Clipboard Widget | `Super + V` (`cliphist`) |
| **Power Menu** | Start &rarr; Power Button | `Super + Escape` (Wofi Power Menu) |
